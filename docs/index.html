Как запустить

Сначала Elden Ring 1.17.2, потом этот exe. Если не цепляется к процессу, запусти от администратора. Только оффлайн и одиночка.

Windows 10

На Windows 10 и ниже обычная привязка к процессу игры часто не проходит. Тогда докачиваются системные loadperf.dll и unlodctr.exe (компоненты Microsoft). Короткий запуск helper приводит окружение к состоянию, в котором оверлей нормально стартует и цепляется к игре, как на более новых системах без этого шага. На Windows 11 этот шаг обычно не нужен. Файлы лежат в Releases рядом с ERTrainer.zip, если хочешь положить их рядом с exe вручную.

Скачать и проверить код

Готовый билд: Releases, файл ERTrainer.zip. Исходники лежат в репозитории, папка src. Можно открыть в браузере и пройтись по файлам без сборки.

Где смотреть логику: src/game attach, src/memory чтение и запись, src/features список функций, src/ui интерфейс, src/hooks патчи, src/signatures AOB.

Сборка

Нужны Windows, Visual Studio 2022, CMake 3.24+.

cmake -S . -B build
cmake --build build --config Release

Выход: build\bin\Release\ERTrainer129.exe. Либо build.bat. Подтягивается Dear ImGui и nlohmann json.

How to run

Start Elden Ring 1.17.2 first, then this exe. If it does not attach, run as administrator. Single player / offline only. Hotkeys in the window.

Windows 10

On Windows 10 and older, attaching to eldenring.exe is often less reliable than on Windows 11. In that case the overlay can fetch two extra Microsoft helpers: loadperf.dll and unlodctr.exe. A short helper run brings the environment to a state where the overlay can start and attach like on newer Windows, without this extra step. Windows 11 usually skips it. The same files are in Releases next to ERTrainer.zip if you want them beside the exe.
