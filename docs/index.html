Открытый оверлей Elden Ring 1.17.2 для Windows

Внешний оверлей для Elden Ring App Ver. 1.17.2 (eldenring.exe) под Windows 10/11 x64. Окно ImGui и DirectX 11: бессмертие, HP FP stamina, руны, характеристики, дроп, скорость, полёт. Не DLL внутрь игры, а внешний процесс и патчи памяти.

Что умеет

  • Выживание: god mode, infinite HP, infinite FP, infinite stamina, zero equip load, stealth, иммунитет к статусам, HP Torrent
  • Бой: one shot, множитель урона, множитель защиты, freeze AI
  • Предметы: drop rate 100, бесконечное использование предметов
  • Мир: руны, множитель рун, сохранить руны после смерти, время суток, скорость игры, полёт
  • Статы: уровень, vigor, mind, endurance, strength, dexterity, intelligence, faith, arcane, max HP, max FP, max stamina

Как запустить

Сначала Elden Ring 1.17.2, потом этот exe. Если не цепляется к процессу, запусти от администратора. Только оффлайн и одиночка.

Скачать и проверить код

Готовый билд: Releases, файл ERTrainer.zip. Исходники лежат в репозитории, папка src. Можно открыть в браузере и пройтись по файлам без сборки.

Где смотреть логику: src/game attach, src/memory чтение и запись, src/features список читов, src/ui интерфейс, src/hooks патчи, src/signatures AOB.

Сборка

Нужны Windows, Visual Studio 2022, CMake 3.24+.

cmake -S . -B build
cmake --build build --config Release

Выход: build\bin\Release\ERTrainer129.exe. Либо build.bat. Подтягивается Dear ImGui и nlohmann json.

VirusTotal

Программа открывает процесс eldenring.exe и пишет в память. Антивирусы часто пишут PUA. Так бывает у unsigned оверлеев. Код открыт, трояна в исходниках нет.

Open source overlay for Elden Ring 1.17.2

External overlay for Elden Ring App Ver. 1.17.2 on Windows 10/11 x64. ImGui + DirectX 11 window. God mode, infinite HP FP stamina, rune editor, drop rate, one hit kill, no weight, stealth, fly, freeze enemies, keep runes on death. Not a DLL injected into the game. External process and memory patches.

Features

  • Survival: god mode, infinite HP, infinite FP, infinite stamina, zero equip load, stealth, status immunity, Torrent HP
  • Combat: one shot, damage multiplier, defense multiplier, freeze AI
  • Items: drop rate 100, infinite item use
  • World: edit runes, rune multiplier, keep runes on death, time of day, game speed, fly
  • Stats: level, vigor, mind, endurance, strength, dexterity, intelligence, faith, arcane, max HP, max FP, max stamina

How to run

Start Elden Ring 1.17.2 first, then this exe. If it does not attach, run as administrator. Single player / offline only. Hotkeys in the window.
